## 🧭 How I work

1. **Depth over breadth** — fewer systems, each deployed with real metrics.
2. **Prove it with numbers** — latency, throughput, accuracy; not adjectives.
3. **Document the judgment** — every system carries ADRs and a written case study; the reasoning is the value.
4. **Simplest thing that satisfies the requirement** — no abstraction without a reason.
